# Titanic Survival Prediction

## Project Overview

This project uses supervised machine learning to predict whether a passenger survived the Titanic disaster based on passenger information such as age, sex, passenger class, and fare.

The goal is to explore the dataset, prepare the data, train classification models, and evaluate their performance.

## Project Objectives

- Explore and understand the Titanic dataset.
- Identify missing values and analyze feature distributions.
- Perform data cleaning and preprocessing.
- Engineer useful features for prediction.
- Train and compare machine learning classification models.
- Evaluate models using accuracy, precision, recall, F1-score, and a confusion matrix.
- Generate survival predictions for the test dataset.

## Dataset

The dataset comes from the [Kaggle Titanic Competition](https://www.kaggle.com/competitions/titanic/data).


The target variable is:

- `0`: Did not survive.
- `1`: Survived.
